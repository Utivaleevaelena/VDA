Cookies & traceurs

Dans la configuration actuelle du site :

  • aucun outil de mesure d’audience n’est installé ;
  • aucun pixel publicitaire n’est installé ;
  • les polices sont hébergées sur le site ;
  • aucun appel à Google Fonts n’est effectué ;
  • aucun cookie publicitaire ou de mesure d’audience n’est déposé ;
  • WhatsApp, LinkedIn et les sites d’agences sont de simples liens externes.

Dans cette configuration, aucun bandeau de consentement n’est nécessaire.

Une nouvelle analyse sera réalisée avant l’ajout de Google Analytics, Meta Pixel, Google Maps embarqué, YouTube / Vimeo embarqué, reCAPTCHA / hCaptcha / Turnstile chargé dans le navigateur, chat externe, heatmap, remarketing ou autre traceur non strictement nécessaire.
